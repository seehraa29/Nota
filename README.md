# Nota
Client side Notes application - runs in Chrome or Edge browsers.

The primary aim of this appication is to be standalone client side only application that stores notes in HTML format.
It supports

  1. Formatting page layout, HTML tables
  2. Code blocks with syntax highlighting
  3. Multiple locations for notes
  4. Encryption of notes
  5. Export/Import
